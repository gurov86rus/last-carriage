# Последний вагон — играбельная сборка

Браузерная аркада студии Minty Pixel: защищаете боевой вагон, пока поезд идёт к станции.
Пять волн, остановки с магазином и бронепоезд-босс в конце.

**Играть:** https://gurov86rus.github.io/last-carriage/

Управление: мышью наводите пушку и удерживаете кнопку. На телефоне — прижмите палец
в нижней полосе и ведите в сторону противника.

Здесь лежит только собранная игра. Исходники, тесты и документ проекта не публикуются.
Это внутренний прототип: рейс не сохраняется, интеграции с игровыми площадками нет.

## 3D-прототип

Отдельная тестовая сцена на Unity: **https://gurov86rus.github.io/last-carriage/3d/**

75 секунд пути, ручная пушка и автоматическая турель. На компьютере: мышь — прицел, левая кнопка — огонь, C — камера, Esc — пауза.

В папке `3d/` опубликована только браузерная сборка. Это ранний прототип; интерфейс пока рассчитан на широкий экран.
